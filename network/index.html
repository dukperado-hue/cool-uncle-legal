แผนที่โครงข่ายโปรเจกต์ของ

dukperado-hue/cool-uncle-legal

เว็บ dukperado-hue/cool-uncle-legal คือแอปหลักของ Cool Uncle Lab ที่เขียนโค้ดต่อเนื่องมาตั้งแต่สร้าง โดยมี ผู้เขียนโค้ด เพียงคนเดียวคือ dukperado-hue (ตัวผู้ใช้เองนั่นแหละ)

กราฟด้านล่างแสดงให้เห็นว่านอกจากเว็บหลักแล้ว dukperado-hue ยังเขียนโค้ดกระจายไปยัง repository อื่น ๆ อีกกี่แห่ง แต่ละอันคือหนึ่งโปรเจกต์ในเครือ Cool Uncle Lab

วงกลมสีส้มตรงกลางคือบัญชี GitHub dukperado-hue ที่เป็นเจ้าของทุก repo เหล่านี้ ส่วนวงกลมสีแดงคือตัวคนเขียนโค้ด (คนเดียวกัน) เชื่อมด้วยเส้นไปยังแต่ละrepository — เส้นยิ่งหนา ยิ่ง commit เยอะ

วิธีอ่านแผนที่นี้ อยู่ด้านล่างของกราฟ

วิธีอ่านแผนภาพนี้

สรุปสั้น ๆ | แผนภาพนี้แสดงว่า dukperado-hue/cool-uncle-legal เชื่อมโยงกับ repository อื่น ๆ ที่ dukperado-hue เขียนโค้ดไว้อย่างไรบ้าง

สี | repo หลัก (cool-uncle-legal) เป็นสีทองตรงกลาง ตัว ผู้เขียนโค้ด เป็นวงกลมสีแดง ส่วน เจ้าของบัญชี GitHub เป็นวงกลมสีส้ม (ในที่นี้คือคนเดียวกัน เพราะเป็นโปรเจกต์เดี่ยว) และrepository อื่น ๆ ทั้งหมดเป็นสีน้ำเงิน

ขนาดวงกลม | ขนาดของวงกลม repository อ้างอิงจากจำนวนดาว (stars) ที่ได้รับบน GitHub ส่วน repo หลัก จะถูกขยายให้เห็นชัดเสมอโดยไม่ขึ้นกับจำนวนดาว

เส้นเชื่อม | เส้นเชื่อมโยง ผู้เขียนโค้ด ไปยัง repository ที่เขียนโค้ดลงไป ความหนาของเส้นแปรผันตามจำนวน commit ที่ทำในแต่ละ repo

การโต้ตอบ | เอาเมาส์ไปวางบนวงกลม เพื่อดูการเชื่อมโยงทั้งหมดของวงกลมนั้น และ คลิก เพื่อตรึงแผนภาพไว้พร้อมไฮไลต์เส้นเชื่อมทั้งหมด สำรวจดูได้ว่าแต่ละโปรเจกต์เชื่อมกันอย่างไร

หมายเหตุเกี่ยวกับข้อมูล

ข้อมูลดึงมาจาก GitHub API สาธารณะของบัญชี dukperado-hue เมื่อวันที่ 23 สิงหาคม 2569 นับเฉพาะ commit ที่ทำจริงบน GitHub เท่านั้น (commit บนเครื่องที่ยังไม่ push จะไม่ถูกนับ)

ดัดแปลงมาจากเครื่องมือโอเพนซอร์ส ORCA Top Contributor Network ของ Nadieh Bremer (Visual Cinnamon) — เปลี่ยนจากการแสดง "ผู้ร่วมพัฒนา repo คนอื่น" มาเป็นการแสดง "โปรเจกต์ทั้งหมดของคนคนเดียว" แทน
