# ตรวจข้อมูลท่าอากาศยาน 43 แห่ง — `bunkfai/data/airports.json`

วันที่ตรวจ: 2026-10-15 · ผู้ตรวจ: Claude (ตรวจเชิงกลไกจากไฟล์ในโปรเจกต์ ไม่ได้เทียบ AIP ต้นฉบับ)

## ที่มาตามที่ระบุในโค้ด (`app.js` บรรทัด 10)
`AIRPORTS: AIP Thailand 2026-07-09 (43 ARP)` พร้อมเขต LHZ รัศมี 10 กม. และแถบ PHZ

## สิ่งที่ตรวจแล้ว (ผ่านด้วยสคริปต์)
| รายการ | ผล |
|---|---|
| จำนวนรายการ airports.json = airports_enhanced.json | 43 = 43 ✅ |
| รหัสซ้ำ | ไม่มี ✅ |
| พิกัดอยู่ในกรอบประเทศไทย (lat 5.5–20.5, lon 97.3–105.7) | ทุกรายการ ✅ |
| มีจังหวัดครบทุกแห่ง และมีข้อมูลโซนใน enhanced ครบ | ✅ |
| `bearingVerified` เป็น true ทุกแห่ง | ✅ (เป็นธงที่ผู้จัดทำตั้งเอง ไม่ใช่การรับรองจาก AIP) |

## ที่พบและควรแก้ / ควรตรวจ
1. **`BTZ` (เบตง) ไม่ใช่รหัส ICAO 4 ตัวอักษร** — ฟิลด์ชื่อ `icao` ของรายการนี้ใส่รหัสแบบ 3 ตัว (รูปแบบ IATA) ขณะที่อีก 42 รายการเป็น `VTxx` ต้องเปิด AIP/AD ของเบตงยืนยันรหัส ICAO ที่ถูกต้อง แล้วแก้ทั้ง airports.json และ airports_enhanced.json (และตรวจว่า `app.js`/`flight_paths.js` อ้างรหัสนี้อยู่หรือไม่ก่อนแก้) — schema.sql บังคับรูปแบบ `^[A-Z]{4}$` จึงจะ import ไม่ผ่านจนกว่าจะแก้
2. **คู่สนามบินใกล้กันมาก (วง LHZ ซ้อนทับ)** — ตรงตามคาด ไม่ใช่ข้อผิดพลาด แต่เจ้าหน้าที่ควรเห็นว่าจุดหนึ่งอาจอยู่ใน LHZ ของสองแห่ง
   - VTSF นครศรีธรรมราช – VTSN ฉะเอียน: 7.7 กม.
   - VTBD ดอนเมือง – VTBS สุวรรณภูมิ: 29.9 กม.
   - VTSH สงขลา – VTSS หาดใหญ่: 36.8 กม.
3. **ความครบถ้วนของรายการ 43 แห่ง** — ตรวจจากไฟล์อย่างเดียวบอกไม่ได้ว่าขาดแห่งใดหรือไม่ ต้องเทียบกับรายการสนามบินที่เกี่ยวข้องในประกาศ/AIP ตามที่กรมการปกครองและ CAAT ใช้อ้างอิง ในรายการปัจจุบันมีทั้งสนามบินพาณิชย์และสนามบินทหาร (เช่น ตาคลี, ฉะเอียน, กำแพงแสน, โคกกระเทียม) ควรให้ CAAT ยืนยันขอบเขตว่า "10 กม. รอบท่าอากาศยาน" ตามประกาศนั้นรวมสนามบินกลุ่มใดบ้าง
4. **วันที่ข้อมูลมีผล (AIRAC cycle)** — โค้ดระบุ 2026-07-09 ควรเก็บในตาราง `airspace_dataset.effective` และแสดงในผลตรวจทุกครั้ง พร้อมกำหนดรอบทบทวนตาม AIRAC (ทุก 28 วัน)
5. **พิกัด ARP** — ไม่ได้เทียบรายตัวกับ AIP ต้นฉบับ ควรสุ่มตรวจอย่างน้อย 10% หรือให้ผู้มีอำนาจของ CAAT ยืนยันทั้งชุด ก่อนเจ้าหน้าที่นำผลตรวจไปประกอบการตัดสินใจ

## ข้อเสนอก่อนประชุม กปค.
- แก้ข้อ 1 ให้เรียบร้อย (ใช้เวลาไม่นาน)
- ขอจาก CAAT: ใครคือเจ้าของข้อมูลอ้างอิงที่ควรใช้ และความถี่ที่ควรอัปเดต
- ในเดโมและระบบจริง ใส่ข้อความ "ผลตรวจอัตโนมัติเป็นตัวช่วย ไม่ใช่คำวินิจฉัย" ทุกหน้าที่แสดงผลตรวจ (ทำแล้วในเดโม)
